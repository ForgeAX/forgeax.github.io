Engine 安定版 v0.5.0：2 週間分のプレビューの成果が安定版に、ブルームを再調整

SDK v0.5.0 が新しい安定版として、v0.4.19 から 2 週間で GitHub Releases に公開されました。複数のディレクショナルライト、大幅に広がった WebGL2 レンダリング、テンポラルアンチエイリアシング、独自の読み込み画面など、この間にプレビューした作業の大半を含み、ブルームを再調整しています。同時にプレビュービルド 3 件も公開しました。

Engine 安定版 v0.5.0：2 週間分のプレビューの成果が安定版に、ブルームを再調整

  • SDK v0.5.0 が新しい安定版です。v0.4.19 から 2 週間で、来歴情報、SPDX ソフトウェア部品表、SHA-256 チェックサムを添えた自己完結型アーカイブとして GitHub Releases に公開しました。同じ 2 日間にプレビュービルド 0.6.0-dev.16819 から 0.6.0-dev.16821 までの 3 件も公開しています。
  • v0.4.19 以降に安定版へ加わったもの：1 つのシーンでの複数のディレクショナルライト、より多くの glTF 拡張、ビデオテクスチャ、メッシュモデリングツール、デバイスに応じたレンダリングパスの自動選択、テンポラルアンチエイリアシングとアップスケーリングを含む大幅に広がった WebGL2 レンダリング、独自の読み込み画面と失敗画面、より速いウォームスタート。
  • 破壊的変更（ブルーム）：bloomIntensity は、明るい光のうちグローとして散乱する割合を表すようになりました。以前に調整したシーンではグローが約 3 分の 1 になるため、同じ見た目を保つには以前の値を 3 倍にしてください。bloomThreshold の既定値は -1（しきい値なし）になり、色付きのエミッシブ面も光ります。しきい値が必要な場合は明示的に設定してください。
  • 破壊的変更（レンズと反射）：色収差は、中心には影響せず四隅に向かって強くなる放射状のフリンジになりました。chromaticAberration は 0 から 5 のパーセント値になり、chromaticAberrationAngle を削除し、chromaticAberrationStartOffset を追加しました。PlanarReflection.distortion は画面上のオフセットではなく、ワールド空間の半径になりました。
  • 空とフォグ：完全な物理ベースの大気が WebGL2 の Forward パスで動作し、フォグが空の背景も覆うようになり Fog.skyOpacity で調整できます。空は太陽の明るさと色合いに従います。ADDITIVE_BLEND マテリアルプリセット、setTransformLookAt ヘルパー、フィルミックなトーンマッピングモードを追加しました。
  • ビデオと色の修正：ゼロコピーのビデオ取り込みに対応しないブラウザーで、通常のテクスチャとして使ったビデオが上下逆になる問題を修正しました。恒等のカラールックアップテーブルは、シャドウを暗くせず映像をそのまま保つようになりました。
  • パフォーマンス：Forward パスに深度プリパスを追加し、物理は静止したボディをポーリングせずに動きの変化を通知し、フレームは自身の GPU 処理が終わりしだい完了として扱われます。Android と iOS のブラウザーでは、描画バッファーの短辺が既定で 720 ピクセルになります。
  • プレビュービルドでは：forgeax project play --release でビルド済みのリリースに対してスクリプト化したプレイスルーを実行でき、--session は実行の間でブラウザーをウォーム状態に保ち、後のステップはゲーム全体を再生せずにセットアップステップから開始でき、mouse.look でマウスルックカメラを回せます。3D スターターは、プレイヤー、カメラ、ワールド、UI の各フォルダーに分かれ、それぞれ個別に削除できます。
