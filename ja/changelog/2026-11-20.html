Engine 安定版 v0.5.1（v0.5.0 から 1 週間）：水、雲、アプリのパッケージング、コミュニティ要望のライト制御

  • SDK v0.5.1 が新しい安定版です。v0.5.0 から 1 週間で、来歴情報、SPDX ソフトウェア部品表、SHA-256 チェックサムを添えた自己完結型アーカイブとして GitHub Releases に公開しました。同じ 3 日間にプレビュービルド 0.6.0-dev.16826 から 0.6.0-dev.16829 までの 4 件も公開しています。
  • v0.5.0 以降に安定版へ入った新機能：水システム（自分のプロジェクトにコピーできる湖のサンプル付き）、クック済みのボリューメトリッククラウド、デスクトップとモバイル向けの Tauri パッケージング、CPU・メモリ・GPU のプロファイリングワークベンチ。デバイスで雲が使えない場合もシーンは動き続けます。
  • コミュニティからの要望：SpotLight.decay が PointLight.decay と揃い、スポットライトのコーン全体で均一な明るさを保てるようになりました。11 月 5 日の GitHub issue で要望されたもので、この安定版にネイティブと Three.js レイヤーの両方で入っています。既定値は 2 で、既存のシーンは変わりません。
  • Three.js 互換：@forgeax/engine/three は Three.js r187 を対象とし、ローダーやコントロールからジオメトリヘルパーまで 100 を超えるアドオンモジュールに加え、ポストエフェクトとポイントカラーに対応しました。Three.js のオブジェクトがネイティブの World を共有することも、実験的な経路として可能です。
  • 品質プリセットとデバイス構成：プロジェクトで quality: { base: { kind: 'device-default' } } を宣言するとデバイス向けの推奨値から始まり、プレイヤーの選択は保存され、app.configuration?.setQuality({ base: { kind: 'preset', preset: 'medium' } }) で実行時に低・中・高を切り替えられます。スクリーンスペースリフレクションは半分の密度でトレースし、フル解像度で再構成できます。
  • テキストとマテリアル：GlyphText に worldOriented が加わり、ラベルをカメラに向ける代わりにエンティティに追従させたり、ゲームに同梱したフォントを使ったりできます。alphaCutoff または alphaHash を使うカットアウトマテリアルは既定で alphaMode: 'opaque' になり、カットアウト部分が灰色になる問題とフレーム全体が暗くなる問題を修正しました。自動露出はフレーム間で履歴を保持します。
  • AI エージェント向け：SDK にエンジンの機能概要が同梱され、スターターのガイダンスは、コードを書く前にそれを読み、既存の機能に沿って計画するようエージェントに指示します。3D スターターは単体テストのひな形をやめて実際のプレイスルーで検証するようになり、forgeax project test はテストファイルのないゲームで成功を返します。
  • プレビュービルドでは：エンジンのツールと起動時のラベルを中国語と英語で利用でき、英語の README に加えて中国語版も用意しました。実行時に GPU で生成するテクスチャがパノラマとボリュームテクスチャに対応し、MSAA 使用時にもアウトラインが保たれます。
  • プレビュービルドではさらに：レベルストリーミングへの第一歩として、レベルを非表示のままバックグラウンドで準備してから実行中のシーンに加えられるようになり、Deferred レンダリングが速くなり、3D スターターの既定の露出がニュートラルになりました。
