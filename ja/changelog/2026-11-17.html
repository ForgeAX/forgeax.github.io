Engine 0.6 プレビュー：水、ボリューメトリッククラウド、デスクトップとモバイル向けパッケージング、プロファイリングワークベンチ

  • 2 日間でプレビュービルド 4 件、0.6.0-dev.16822 から 0.6.0-dev.16825 までを公開しました。
  • 水：最初の水システムが @forgeax/engine-water として加わりました。水域とゾーン、波で動く水面、反射と水中ビュー、浮力と泡、局所的な波紋シミュレーションを備えています。サンプルシーンは港から海岸線まであります。
  • ボリューメトリッククラウド：クック済みの雲レイヤーを新しい VolumetricCloudLayer コンポーネントで描画します。雲をクックするツールは SDK のオーサリングツールに含まれます。
  • デスクトップとモバイル向けパッケージング：新しい forgeax project package --format tauri --platform windows|macos|linux|android|ios がネイティブインストーラーを生成し、forgeax project build --target tauri が通常のブラウザービルドから生成する Tauri プロジェクトは、デスクトップに加えて Android と iOS にも対応しました。Windows と Android 向けの修正は、すぐ次のビルドで入りました。
  • プロファイリングワークベンチをエンジンに同梱：CPU タイムラインとコールツリー、メモリスナップショットとアロケーションプロファイル、GPU リソースとタイミングのレポート。いずれもインタラクティブな HTML レポートとして出力され、AI エージェントが照会できる機械可読データも付属します。
  • ライティングと画質：3D スターターのカメラが自動露出を使うようになり、晴天のライティングを刷新し、GPU で生成した舗装テクスチャを追加しました。空の下部が正しく描画され、フォグが MSAA とともに動作し、MSAA と FXAA を併用でき、GPU 生成テクスチャがネイティブのアセット種別になりました。
  • ECS の破壊的変更：システム、スケジュール、リソースは、定義してインポートしたオブジェクト（defineSystem、defineSchedule、defineResource）で識別されるようになり、名前は診断用のラベルにすぎません。システムは world.addSystem(Update, defineSystem({ ... })) で登録してください。あわせて、スローモーションと一時停止のための world.acquireTimeScale(scale) を追加しました。動き続ける必要があるエフェクトは Time.unscaledDelta を読み取れます。
  • シャドウとビルド：DirectionalLight.staticShadowCache はオプトイン（既定値 false）になり、影を落とさないオブジェクトによって無効化されなくなりました。devkitAppOptions.canvasPixelRatio は 'device' または { mode: 'device', max: 2 } を受け付け、単一 HTML パッケージは既定でコンパクト形式になり（--compress=false でプレーン JSON に戻せます）、本番ビルドは既定でビルドキャッシュのクック済みマテリアルを再利用します。
  • より速く、より軽く：メッシュは実行時に単一の表現だけを保持してメモリ使用量を抑え、使われなくなったマテリアルプログラムは回収され、大きな階層のトランスフォーム更新が速くなりました。
