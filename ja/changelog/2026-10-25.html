Engine 0.5 プレビュー：計測に基づく読み込み進捗、正確なパッケージプレビュー、より確実なエージェント向けツール

  • 2 日間でプレビュービルド 5 件（0.5.0-dev.15096 から 0.5.0-dev.15779）を公開しました。
  • 読み込みを計測可能に：起動カバーは後戻りしない実測の進捗を表示します。読み込みタイムラインは既定で有効になり、Worker の起動、パッケージの読み込み、パイプライン作成、最初に表示されたフレームを記録し、markLoadTimeline で独自のマークも追加できます。
  • 出荷内容を把握：公開前にプレイヤーがダウンロードする正確なバイト数をプレビューし、Bundle の転送を確認できます。WeChat ミニゲームのパッケージはアセットを効率よくまとめ、起動とキーボードフォーカスを強化しました。
  • AI エージェントにも人にも確実なツール：DevKit のライブコマンドは信頼性が上がり、入力の準備完了を待ち、出力が簡潔になりました。新規ゲームプロジェクトで型チェックに失敗していた SDK ドキュメントのサンプルは、実際のプロジェクトで問題になった後に修正しました。
  • SDK に View アセットプレビューワークスペースが同梱され、三角形単位の正確なピッキングを備えたマテリアルと UV のプレビュー操作も含まれます。メッシュのジオメトリは描画せずに読み戻せます。
  • パフォーマンス：各フレームが停滞の理由とコンパイル・パイプラインのカウンターを報告し、Worker のメモリとガベージコレクションの負荷が減り、任意のパイプラインライブラリをバックグラウンドでウォームアップし、描画チェーンのコストはシーンの大きさではなく変更量に比例するようになりました。
  • メンテナンス：依存関係の HTTP と URI パーサーの脆弱性を修正し、ツールチェーンを npm 12.2.1 と pnpm 12.15.0 に更新し、zstd デコードのメモリ使用量に上限を設けました。
