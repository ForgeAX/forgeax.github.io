Engine 0.5 Vorschau: SDK-Downloads auf GitHub Releases, kleinere Spielpakete, ein Start, der sich erholt

Sechs Vorschau-Builds in zwei Tagen, und das stabile SDK steht jetzt auf GitHub Releases zum Download bereit. Spielpakete wurden kleiner, der Start wartet auf langsamen Rechnern und erklärt sich, statt aufzugeben, der WebGL2-Fallback ist stabiler, und die Physik legt Solver-Einstellungen offen.

Engine 0.5 Vorschau: SDK-Downloads auf GitHub Releases, kleinere Spielpakete, ein Start, der sich erholt

  • Sechs Vorschau-Builds in zwei Tagen, 0.5.0-dev.15784 bis 0.5.0-dev.15789.
  • Stabiles SDK auf GitHub Releases: SDK v0.4.18 und v0.4.19 sind im öffentlichen Repository als eigenständiges Browser-Spiele-SDK-Archiv veröffentlicht, mit Herkunftsnachweis, SPDX-Software-Stückliste und SHA-256-Prüfsummen.
  • Kleinere Spielpakete, und Material-Shader werden erst vorbereitet, wenn sie zum ersten Mal gebraucht werden, statt alle vorab.
  • Ein Start, der sich erholt: Ein langsamer Start wartet jetzt weiter und zeigt aufklappbare Diagnosen, statt fehlzuschlagen, das Standard-Laden eines Spiels erholt sich von zwischengespeicherten Fehlern, und das Laden funktioniert unter einer strikten Content Security Policy.
  • Stabilerer WebGL2-Fallback: Der Fallback wird einmal gewählt, behält die von beiden Backends gemeldeten Gründe und hält Belichtung und Bildressourcen auf schwächeren Geräten korrekt.
  • Physik: Die Solver-Iterationen sind jetzt konfigurierbar, der Solver nutzt SIMD, und die kontinuierliche Kollisionserkennung gegen Voxel-Welten kostet in unserem Replay-Benchmark etwa ein Drittel weniger.
  • Weniger Arbeit in stabilen Bildern: Die Bildvorbereitung belegt weniger Speicher, die Garbage Collection im Worker ging zurück, unveränderte Animationsuhren werden nicht mehr neu geschrieben, und das ECS erhielt allokationsarme, schreibgeschützte Abfrage-Batches.
  • WeChat-Minispiel: Die Szene wird innerhalb eines festen Auflösungsbudgets gerendert, das sich mit maxRenderShortSide ändern lässt, während Canvas, UI und Eingabe in nativer Auflösung bleiben; Browser-Builds sind nicht betroffen.
