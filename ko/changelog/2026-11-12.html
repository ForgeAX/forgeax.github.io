Engine 안정 버전 v0.5.0: 2주간의 프리뷰 작업이 안정 버전으로, 블룸 재보정

SDK v0.5.0이 v0.4.19 이후 2주 만에 새 안정 버전으로 GitHub Releases에 공개되었습니다. 여러 개의 방향광, 크게 넓어진 WebGL2 렌더링, 템포럴 안티에일리어싱, 나만의 로딩 화면 등 그동안 프리뷰한 작업 대부분을 담았고 블룸을 재보정했습니다. 프리뷰 빌드 3개도 함께 공개했습니다.

Engine 안정 버전 v0.5.0: 2주간의 프리뷰 작업이 안정 버전으로, 블룸 재보정

  • SDK v0.5.0이 새 안정 버전입니다. v0.4.19 이후 2주 만에, 출처 증명과 SPDX 소프트웨어 자재 명세서, SHA-256 체크섬을 갖춘 독립형 아카이브로 GitHub Releases에 공개했습니다. 같은 이틀 동안 프리뷰 빌드 0.6.0-dev.16819부터 0.6.0-dev.16821까지 3개도 공개했습니다.
  • v0.4.19 이후 안정 버전에 새로 들어온 것: 한 장면의 여러 방향광, 더 많은 glTF 확장, 비디오 텍스처, 메시 모델링 도구, 기기에 따른 렌더링 경로 자동 선택, 템포럴 안티에일리어싱과 업스케일링을 포함해 크게 넓어진 WebGL2 렌더링, 나만의 로딩 화면과 실패 화면, 더 빠른 웜 스타트.
  • 호환성이 깨지는 변경(블룸): bloomIntensity가 이제 밝은 빛 가운데 글로로 산란되는 비율을 뜻합니다. 예전에 맞춰 둔 장면은 글로가 약 3분의 1로 줄어들므로, 같은 모습을 유지하려면 이전 값에 3을 곱하세요. bloomThreshold의 기본값은 임계값이 없음을 뜻하는 -1이 되어 색이 있는 발광 표면도 빛납니다. 임계값이 필요하면 직접 설정하세요.
  • 호환성이 깨지는 변경(렌즈와 반사): 색수차가 이제 중심은 그대로 두고 모서리로 갈수록 커지는 방사형 프린지입니다. chromaticAberration은 0에서 5 사이의 퍼센트 값이 되었고, chromaticAberrationAngle은 제거되었으며 chromaticAberrationStartOffset이 추가되었습니다. PlanarReflection.distortion은 화면 오프셋이 아니라 월드 공간 반지름입니다.
  • 하늘과 안개: 완전한 물리 기반 대기가 WebGL2 Forward 경로에서 동작하고, 안개가 이제 하늘 배경까지 덮으며 Fog.skyOpacity로 조절할 수 있습니다. 하늘은 태양의 밝기와 색조를 따릅니다. ADDITIVE_BLEND 머티리얼 프리셋, setTransformLookAt 헬퍼, 필믹 톤 매핑 모드를 추가했습니다.
  • 비디오와 색상 수정: 제로 카피 비디오 가져오기를 지원하지 않는 브라우저에서 일반 텍스처로 쓴 비디오가 위아래로 뒤집히던 문제를 수정했고, 항등 색상 룩업 테이블이 이제 어두운 영역을 더 어둡게 하지 않고 화면을 그대로 유지합니다.
  • 성능: Forward 경로에 깊이 프리패스를 추가했고, 물리는 정지한 바디를 폴링하지 않고 움직임 변화를 알리며, 프레임은 자신의 GPU 작업이 끝나는 즉시 완료로 처리됩니다. Android와 iOS 브라우저에서는 드로잉 버퍼의 짧은 변이 기본 720픽셀입니다.
  • 프리뷰 빌드에서는: forgeax project play --release로 빌드된 릴리스에 대해 스크립트 플레이스루를 실행할 수 있고, --session은 실행 사이에 브라우저를 웜 상태로 유지하며, 뒤쪽 단계는 게임 전체를 다시 재생하지 않고 준비 단계에서 시작할 수 있고, mouse.look으로 마우스 룩 카메라를 돌릴 수 있습니다. 3D 스타터는 이제 플레이어, 카메라, 월드, UI 폴더로 나뉘며 각각 따로 삭제할 수 있습니다.
