Engine 0.6 프리뷰: 물, 볼류메트릭 클라우드, 데스크톱 및 모바일 패키징, 프로파일링 워크벤치

이틀 동안 프리뷰 빌드 4개. 첫 번째 물 시스템과 쿠킹된 볼류메트릭 클라우드가 추가되고, 게임을 데스크톱 및 모바일 앱으로 패키징할 수 있으며, CPU·메모리·GPU 프로파일링 워크벤치가 엔진과 함께 제공되고, 3D 스타터에는 자동 노출과 바로잡힌 하늘 아랫부분이 들어갔습니다.

Engine 0.6 프리뷰: 물, 볼류메트릭 클라우드, 데스크톱 및 모바일 패키징, 프로파일링 워크벤치

  • 이틀 동안 프리뷰 빌드 4개, 0.6.0-dev.16822부터 0.6.0-dev.16825까지 공개했습니다.
  • 물: 첫 번째 물 시스템이 @forgeax/engine-water로 추가되었습니다. 수역과 구역, 파도로 움직이는 수면, 반사와 수중 뷰, 부력과 거품, 국소 물결 시뮬레이션을 갖추었습니다. 샘플 장면은 항구부터 해안선까지 있습니다.
  • 볼류메트릭 클라우드: 쿠킹된 구름 레이어를 새로운 VolumetricCloudLayer 컴포넌트로 렌더링하며, 구름 쿠커가 SDK 저작 도구에 포함됩니다.
  • 데스크톱 및 모바일 패키징: 새로 추가된 forgeax project package --format tauri --platform windows|macos|linux|android|ios가 네이티브 설치 파일을 만들고, forgeax project build --target tauri가 일반 브라우저 빌드에서 생성하는 Tauri 프로젝트는 이제 데스크톱뿐 아니라 Android와 iOS도 지원합니다. Windows와 Android용 수정은 바로 다음 빌드에 반영되었습니다.
  • 프로파일링 워크벤치가 엔진과 함께 제공됩니다: CPU 타임라인과 콜 트리, 메모리 스냅숏과 할당 프로파일, GPU 리소스 및 타이밍 보고서. 각각 인터랙티브 HTML 보고서로 제공되며, AI 에이전트가 조회할 수 있는 기계 판독용 데이터가 함께 나옵니다.
  • 조명과 화질: 3D 스타터의 카메라가 이제 자동 노출을 사용하고, 맑은 날 조명을 새로 다듬었으며, GPU에서 생성한 포장 텍스처를 추가했습니다. 하늘 아랫부분이 올바르게 렌더링되고, 안개가 MSAA와 함께 동작하며, MSAA와 FXAA를 함께 쓸 수 있고, GPU 생성 텍스처가 네이티브 에셋 유형이 되었습니다.
  • ECS의 호환성이 깨지는 변경: 시스템, 스케줄, 리소스는 이제 직접 정의하고 임포트한 객체(defineSystem, defineSchedule, defineResource)로 식별되며, 이름은 진단용 레이블일 뿐입니다. 시스템은 world.addSystem(Update, defineSystem({ ... }))로 등록하세요. 또한 슬로 모션과 일시 정지를 위한 world.acquireTimeScale(scale)가 추가되었으며, 계속 재생되어야 하는 효과는 Time.unscaledDelta를 읽으면 됩니다.
  • 그림자와 빌드: DirectionalLight.staticShadowCache는 이제 직접 켜야 하며(기본값 false), 그림자를 드리우지 않는 객체 때문에 무효화되지 않습니다. devkitAppOptions.canvasPixelRatio는 'device' 또는 { mode: 'device', max: 2 }를 받고, 단일 HTML 패키지는 기본적으로 압축 형식이며(--compress=false로 일반 JSON 복원), 프로덕션 빌드는 기본적으로 빌드 캐시의 쿠킹된 머티리얼을 재사용합니다.
  • 더 빠르고 가볍게: 메시가 런타임에 하나의 표현만 유지해 메모리 사용량이 줄고, 더 이상 쓰이지 않는 머티리얼 프로그램은 회수되며, 큰 계층 구조의 트랜스폼 업데이트가 빨라졌습니다.
