Engine 안정 버전 v0.5.1, v0.5.0 이후 일주일: 물, 구름, 앱 패키징, 커뮤니티가 요청한 조명 제어

SDK v0.5.1이 v0.5.0 이후 일주일 만에 새 안정 버전으로 GitHub Releases에 공개되었습니다. 물, 볼류메트릭 클라우드, 데스크톱 및 모바일 패키징, 프로파일링 워크벤치가 안정 버전에 들어왔고, 커뮤니티 요청으로 SpotLight.decay가 추가되었으며, 품질 프리셋이 기기에 맞는 설정을 골라 줍니다. 프리뷰 빌드 4개도 함께 공개했습니다.

Engine 안정 버전 v0.5.1, v0.5.0 이후 일주일: 물, 구름, 앱 패키징, 커뮤니티가 요청한 조명 제어

  • SDK v0.5.1이 새 안정 버전입니다. v0.5.0 이후 일주일 만에, 출처 증명과 SPDX 소프트웨어 자재 명세서, SHA-256 체크섬을 갖춘 독립형 아카이브로 GitHub Releases에 공개했습니다. 같은 사흘 동안 프리뷰 빌드 0.6.0-dev.16826부터 0.6.0-dev.16829까지 4개도 공개했습니다.
  • v0.5.0 이후 안정 버전에 새로 들어온 것: 물 시스템(내 프로젝트로 복사해 쓸 수 있는 호수 예제 포함), 쿠킹된 볼류메트릭 클라우드, Tauri로 만드는 데스크톱 및 모바일용 네이티브 설치 파일, CPU·메모리·GPU 프로파일링 워크벤치. 기기에서 구름을 쓸 수 없어도 장면은 계속 실행됩니다.
  • 11월 17일에 프리뷰로 공개한 두 가지 호환성이 깨지는 변경도 안정 버전에 들어왔습니다. 시스템, 스케줄, 리소스는 정의한 객체로 식별되며 시스템은 world.addSystem(Update, defineSystem({ ... }))로 등록합니다. DirectionalLight.staticShadowCache는 옵트인(기본값 false)이 되었습니다. world.acquireTimeScale(scale)를 통한 시간 스케일, forgeax project play --release를 통한 릴리스 빌드 플레이스루, dev look --view luminance 밝기 맵도 안정 버전에서 쓸 수 있습니다.
  • 커뮤니티의 요청: SpotLight.decay가 이제 PointLight.decay와 같은 방식으로 동작해, 스포트라이트가 원뿔 전체에서 고른 밝기를 유지할 수 있습니다. 11월 5일 GitHub 이슈에서 요청된 기능으로, 이번 안정 버전에 네이티브와 Three.js 레이어 모두 포함되었습니다. 기본값은 2여서 기존 장면은 달라지지 않습니다.
  • Three.js 호환: @forgeax/engine/three가 이제 Three.js r187을 대상으로 하며, 로더와 컨트롤부터 지오메트리 헬퍼까지 100개가 넘는 애드온 모듈과 포스트 이펙트, 포인트 색상을 지원합니다. Three.js 객체가 네이티브 World를 공유하는 것도 실험적 경로로 가능합니다.
  • 품질 프리셋과 기기 구성: 프로젝트에서 quality: { base: { kind: 'device-default' } }를 선언하면 기기에 맞는 권장값에서 시작하고, 플레이어의 선택이 저장되며, app.configuration?.setQuality({ base: { kind: 'preset', preset: 'medium' } })로 실행 중에 낮음·중간·높음을 전환할 수 있습니다. 스크린 스페이스 반사는 절반 밀도로 추적한 뒤 전체 해상도로 재구성할 수 있습니다.
  • 텍스트와 머티리얼: GlyphText에 worldOriented가 추가되어 레이블이 카메라를 향하는 대신 엔티티를 따라갈 수 있고, 게임에 포함한 폰트를 쓸 수 있습니다. alphaCutoff 또는 alphaHash를 쓰는 컷아웃 머티리얼은 이제 기본값이 alphaMode: 'opaque'여서, 컷아웃 부분이 회색으로 보이고 프레임 전체가 어두워지던 문제가 해결되었습니다. 자동 노출은 프레임 사이에 이력을 유지합니다.
  • AI 에이전트를 위해: SDK에 엔진 기능 개요가 포함되고, 스타터 가이드는 에이전트가 코드를 쓰기 전에 그것을 읽고 기존 기능에 맞춰 계획하도록 안내합니다. 3D 스타터는 단위 테스트 틀을 없애고 실제 플레이스루로 검증하며, forgeax project test는 테스트 파일이 없는 게임에서 성공을 반환합니다.
  • 도구: v0.5.1부터 선택 사항인 View 에셋 워크스페이스가 @forgeax/engine npm 패키지에 함께 들어 있습니다. npm으로 설치한 게임은 프로젝트 루트에서 node ./node_modules/@forgeax/engine/tools/view/start.mjs --project . 명령으로 열 수 있습니다.
  • 프리뷰 빌드에서는: 엔진 도구와 시작 화면 레이블을 중국어와 영어로 사용할 수 있고, 영어 README와 함께 중국어 README를 제공합니다. 실행 중 GPU에서 생성하는 텍스처가 이제 파노라마와 볼륨 텍스처를 지원하며, MSAA에서도 외곽선이 유지됩니다.
  • 프리뷰 빌드에는 또한: 레벨 스트리밍을 향한 첫 단계로, 레벨을 숨긴 상태로 백그라운드에서 준비한 뒤 실행 중인 장면에 합류시킬 수 있고, Deferred 렌더링이 더 빨라졌으며, 3D 스타터의 기본 노출이 중립적으로 바뀌었습니다.
