Engine 0.5 프리뷰: GitHub Releases의 SDK 다운로드, 더 작은 게임 패키지, 스스로 복구하는 시작 과정

이틀 동안 프리뷰 빌드 6개, 그리고 안정 버전 SDK를 이제 GitHub Releases에서 내려받을 수 있습니다. 게임 패키지가 작아졌고, 느린 기기에서는 시작을 포기하지 않고 기다리며 상황을 설명하고, WebGL2 폴백이 더 안정적이며, 물리에서 솔버 설정을 공개했습니다.

Engine 0.5 프리뷰: GitHub Releases의 SDK 다운로드, 더 작은 게임 패키지, 스스로 복구하는 시작 과정

  • 이틀 동안 프리뷰 빌드 6개(0.5.0-dev.15784 ~ 0.5.0-dev.15789)를 공개했습니다.
  • GitHub Releases의 안정 버전 SDK: SDK v0.4.18과 v0.4.19를 출처 증명, SPDX 소프트웨어 자재 명세서, SHA-256 체크섬이 포함된 독립형 브라우저 게임 SDK 아카이브로 공개 저장소에 게시했습니다.
  • 게임 패키지가 작아졌고, 머티리얼 셰이더는 처음에 한꺼번에 준비하지 않고 처음 필요할 때 준비합니다.
  • 스스로 복구하는 시작 과정: 시작이 느려도 실패하지 않고 계속 기다리며 펼쳐 볼 수 있는 진단 정보를 보여 주고, 기본 게임 로딩이 캐시된 실패에서 복구되며, 엄격한 콘텐츠 보안 정책에서도 로딩됩니다.
  • 더 안정적인 WebGL2 폴백: 폴백을 한 번만 선택하고, 두 백엔드가 보고한 원인을 모두 보존하며, 저사양 기기에서도 노출과 프레임 리소스를 올바르게 유지합니다.
  • 물리: 솔버 반복 횟수를 설정할 수 있고, 솔버가 SIMD를 사용하며, 복셀 월드에 대한 연속 충돌 감지 비용이 리플레이 벤치마크에서 약 3분의 1 줄었습니다.
  • 안정된 프레임에서 더 적은 작업: 프레임 준비의 메모리 할당이 줄고, Worker 가비지 컬렉션이 감소했으며, 변하지 않은 애니메이션 클록을 다시 쓰지 않고, ECS에 할당이 적은 읽기 전용 쿼리 배치가 추가되었습니다.
  • WeChat 미니게임: 장면은 고정된 해상도 예산 안에서 렌더링되며 maxRenderShortSide로 바꿀 수 있고, 캔버스, UI, 입력은 네이티브 해상도를 유지합니다. 브라우저 빌드에는 영향이 없습니다.
