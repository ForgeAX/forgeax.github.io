引擎稳定版 v0.5.1，距 v0.5.0 一周：水体、云、应用打包，以及社区提出的灯光控制

SDK v0.5.1 是新的稳定版，已发布到 GitHub Releases，距 v0.5.0 一周。水体、体积云、桌面和移动端打包以及性能分析工作台现已进入稳定版；SpotLight.decay 应社区请求加入；画质预设会按设备选出合适的设置。同时还发布了四个预览版本。

引擎稳定版 v0.5.1，距 v0.5.0 一周：水体、云、应用打包，以及社区提出的灯光控制

  • SDK v0.5.1 是新的稳定版，距 v0.5.0 一周，以自包含压缩包的形式发布在 GitHub Releases，附带来源证明、SPDX 软件物料清单和 SHA-256 校验和。同样这三天里还发布了四个预览版本：0.6.0-dev.16826 至 0.6.0-dev.16829。
  • 自 v0.5.0 以来进入稳定版的新内容：水体系统（现在附带一个可以直接复制到自己项目里的湖泊示例）、预烘焙体积云、通过 Tauri 生成的桌面和移动端原生安装包，以及 CPU、内存、GPU 性能分析工作台。设备不支持云时，场景会照常运行。
  • 同样进入稳定版的，还有 11 月 17 日预览过的两项破坏性改动：系统、调度和资源改为以你定义的对象来标识，注册系统写作 world.addSystem(Update, defineSystem({ ... }))；DirectionalLight.staticShadowCache 改为按需开启（默认 false）。时间缩放 world.acquireTimeScale(scale)、针对发布包的试玩 forgeax project play --release，以及 dev look --view luminance 亮度图也都进入了稳定版。
  • 社区提出的需求：SpotLight.decay 现在与 PointLight.decay 对齐，聚光灯可以在整个光锥内保持均匀亮度。这个需求是 11 月 5 日在一条 GitHub issue 里提出的，本次稳定版已经包含，原生路径和 Three.js 兼容层都支持。默认值为 2，已有场景不受影响。
  • Three.js 兼容：@forgeax/engine/three 现在对齐 Three.js r187，覆盖一百多个附加模块，涵盖加载器、控制器和几何工具，还支持后处理效果和点颜色。Three.js 对象也可以共用一个原生 World，这是一条实验性路径。
  • 画质预设和设备配置：项目声明 quality: { base: { kind: 'device-default' } } 即可从针对设备的推荐值起步，玩家的选择会被保存，app.configuration?.setQuality({ base: { kind: 'preset', preset: 'medium' } }) 可在运行时切换低、中、高三档。屏幕空间反射可以用半密度追踪，再以全分辨率重建。
  • 文字和材质：GlyphText 新增 worldOriented，标签可以跟随所在实体的朝向而不是始终面向相机，并且可以使用随游戏打包的字体。使用 alphaCutoff 或 alphaHash 的镂空材质现在默认 alphaMode: 'opaque'，修复了镂空处发灰和整帧变暗的问题。自动曝光会在帧与帧之间保留历史。
  • 面向 AI 智能体：SDK 附带一份引擎能力速览，起步指引会让智能体在写代码之前先读它，并对照已有能力做计划。3D 起步模板去掉了单元测试脚手架，改以真实试玩来验证；forgeax project test 在游戏没有测试文件时返回成功。
  • 工具：从 v0.5.1 起，可选的 View 资源工作区随 @forgeax/engine npm 包一起提供；用 npm 安装的游戏在项目根目录运行 node ./node_modules/@forgeax/engine/tools/view/start.mjs --project . 就能打开它。
  • 预览版本中：引擎工具和启动界面的文字现在提供中文和英文，README 也在英文之外提供中文版。运行时在 GPU 上生成的纹理现在覆盖全景图和体积纹理，描边在开启 MSAA 时得以保留。
  • 预览版本中还有：关卡流式加载迈出第一步，关卡可以在隐藏状态下于后台准备好，再加入正在运行的场景；Deferred 渲染更快；3D 起步场景采用中性的默认曝光。
