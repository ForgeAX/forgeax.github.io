引擎 0.6 预览版：水体、体积云、桌面和移动端打包、性能分析工作台

两天四个预览版本。首个水体系统和预烘焙体积云到来；游戏可以打包成桌面和移动应用；引擎自带 CPU、内存、GPU 性能分析工作台；3D 起步场景有了自动曝光，天空下半部分得到修正。

引擎 0.6 预览版：水体、体积云、桌面和移动端打包、性能分析工作台

  • 两天四个预览版本，从 0.6.0-dev.16822 到 0.6.0-dev.16825。
  • 水体：首个水体系统以 @forgeax/engine-water 的形式到来，包含水体和水域、波浪驱动的水面、反射和水下视图、浮力和泡沫，以及局部涟漪模拟。示例场景从港口到海岸都有。
  • 体积云：预烘焙的云层通过新的 VolumetricCloudLayer 组件渲染，云的烘焙工具已包含在 SDK 的创作工具中。
  • 桌面和移动端打包：新增的 forgeax project package --format tauri --platform windows|macos|linux|android|ios 生成原生安装包；forgeax project build --target tauri 基于普通浏览器构建生成的 Tauri 工程，现在除了桌面也覆盖 Android 和 iOS。针对 Windows 和 Android 的修复在紧接着的下一个版本就跟上了。
  • 引擎自带性能分析工作台：CPU 时间线和调用树、内存快照和分配分析、GPU 资源和耗时报告。每一项都会生成可交互的 HTML 报告，同时附带 AI 智能体可以查询的机器可读数据。
  • 光照和画质：3D 起步场景的相机现在使用自动曝光，晴天光照做了更新，并带有一张在 GPU 上生成的铺地纹理。天空的下半部分现在渲染正确，雾可以和 MSAA 一起使用，MSAA 可以与 FXAA 组合，GPU 生成的纹理成为原生资源类型。
  • ECS 的不兼容变更：系统、调度和资源现在由你定义并导入的对象来标识（defineSystem、defineSchedule、defineResource），名称只作为诊断用的标签。注册系统请写 world.addSystem(Update, defineSystem({ ... }))。另外新增 world.acquireTimeScale(scale)，用于慢动作和暂停，需要继续播放的效果可以读取 Time.unscaledDelta。
  • 阴影和构建：DirectionalLight.staticShadowCache 现在需要主动开启（默认 false），并且不再被不投射阴影的物体触发失效。devkitAppOptions.canvasPixelRatio 接受 'device' 或 { mode: 'device', max: 2 }；生产构建默认复用构建缓存中已烘焙的材质。
  • 更快、更省：网格在运行时只保留一份表示，内存占用更低；不再使用的材质程序会被回收；大型层级的变换更新更快。
