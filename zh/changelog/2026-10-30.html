引擎 0.5 预览版：SDK 可从 GitHub Releases 下载、更小的游戏包、可自行恢复的启动

  • 两天内发布六个预览版本：0.5.0-dev.15784 至 0.5.0-dev.15789。
  • 稳定版 SDK 上线 GitHub Releases：SDK v0.4.18 和 v0.4.19 已发布在公开仓库，是一个自包含的浏览器游戏 SDK 压缩包，附带来源证明、SPDX 软件物料清单和 SHA-256 校验和。
  • 游戏包更小，材质着色器改为在首次用到时才准备，而不是启动时全部准备。
  • 启动可自行恢复：启动较慢时会继续等待，并显示可展开的诊断信息，而不是直接失败；默认的游戏加载可以从缓存的失败中恢复；在严格的内容安全策略（CSP）下也能正常加载。
  • WebGL2 回退更稳定：回退只选择一次，并保留两个后端各自报告的原因；在低端设备上曝光和帧资源也保持正确。
  • 物理：求解器迭代次数现在可以配置，求解器启用了 SIMD；在我们的回放基准中，针对体素世界的连续碰撞检测开销减少约三分之一。
  • 稳定帧的工作更少：帧准备阶段的内存分配减少，Worker 的垃圾回收开销下降，没有变化的动画时钟不再重复写入，ECS 新增低分配的只读查询批次。
  • 微信小游戏：场景在固定的分辨率预算内渲染，可用 maxRenderShortSide 调整，画布、UI 和输入保持原生分辨率；浏览器构建不受影响。
