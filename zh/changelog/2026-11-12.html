引擎稳定版 v0.5.0：两周的预览成果进入稳定版，辉光重新校准

SDK v0.5.0 是新的稳定版，已发布到 GitHub Releases，距 v0.4.19 两周。它带上了这段时间预览过的大部分工作，包括多个平行光、大幅扩充的 WebGL2 渲染、时间抗锯齿和自定义加载界面，并重新校准了辉光。同时还发布了三个预览版本。

引擎稳定版 v0.5.0：两周的预览成果进入稳定版，辉光重新校准

  • SDK v0.5.0 是新的稳定版，距 v0.4.19 两周，以自包含压缩包的形式发布在 GitHub Releases，附带来源证明、SPDX 软件物料清单和 SHA-256 校验和。同样这两天里还发布了三个预览版本：0.6.0-dev.16819 至 0.6.0-dev.16821。
  • 稳定版相对 v0.4.19 新增：同一场景中的多个平行光、更多 glTF 扩展、视频纹理、网格建模工具、按设备自动选择渲染路径、大幅扩充的 WebGL2 渲染（包括时间抗锯齿和超分）、自定义加载和失败界面，以及更快的热启动。
  • 不兼容变更（辉光）：bloomIntensity 现在表示高亮光线中被散射成辉光的比例，因此之前调好的场景只剩约三分之一的辉光；把原来的值乘以 3 即可保持原有效果。bloomThreshold 的默认值改为 -1，即不设阈值，彩色自发光表面也会产生辉光；需要阈值时请显式设置。
  • 不兼容变更（镜头与反射）：色差现在是径向色散，画面中心不受影响，越靠近角落越明显。chromaticAberration 改为 0 到 5 的百分比，移除 chromaticAberrationAngle，新增 chromaticAberrationStartOffset。PlanarReflection.distortion 现在是世界空间半径，不再是屏幕偏移量。
  • 天空与雾：完整的物理大气可在 WebGL2 的 Forward 路径上运行；雾现在会覆盖天空背景，可用 Fog.skyOpacity 控制；天空会跟随太阳的亮度和色调；新增 ADDITIVE_BLEND 材质预设、setTransformLookAt 辅助函数和一个电影感色调映射模式。
  • 视频与颜色修复：在不支持零拷贝视频导入的浏览器里，用作普通纹理的视频不再上下颠倒；恒等的颜色查找表现在不会改变画面，而不是压暗暗部。
  • 性能：Forward 路径新增深度预通道；物理不再轮询静止刚体，而是在运动状态变化时通知；一帧自己的 GPU 工作完成后立即计入完成；在 Android 和 iOS 浏览器中，绘制缓冲区的短边默认为 720 像素。
  • 预览版本中：forgeax project play --release 可以对已构建的发布版本运行你的脚本试玩，--session 在多次运行之间保持浏览器热启动，后面的步骤可以从一个准备步骤开始而不必重放整局，mouse.look 可以转动鼠标视角相机。3D 起步模板现在拆成玩家、相机、世界和 UI 四个文件夹，每个都可以单独删除。
