YINTAI

The hero mech of Tiangong Warframe, exactly as the game ships it. Every armour panel is a NURBS surface written in code on the ForgeAX engine — no imported model or texture files, nothing sculpted by hand.

Modelled in code by an AI agent

YINTAI is 8 source files, about 4,100 lines of TypeScript. Thirty joints are fixed first; the armour is then assembled piece by piece from the engine's high-degree NURBS surfaces, working from a single concept image.

High-poly and low-poly are the same code

Sampled densely, the code yields a 3,607,350-triangle reference model. Sampled at game density it yields the 72,157 triangles shown here, about 2 %. The chord heat map shows how far each triangle sits from the true surface.

Six draw calls, one small atlas

The whole mech is six sub-meshes. Rivets, bolts and other small parts are baked into one 512² normal / AO atlas, and one 30-joint skeleton drives both the mech and the fighter.
