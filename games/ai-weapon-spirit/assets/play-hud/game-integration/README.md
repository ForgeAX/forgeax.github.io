# 游戏 HUD 覆盖包接入增量

`overlay/` 的 UI 20261028-2021 包文件逐字节保留。此目录仅承载游戏侧已验证的 UI 接入保护，入口在语言/皮肤脚本之前加载；不改变游戏状态、输入、数值或存档动作。

- `overlay-integration.css`：恢复原生竖屏装备/商店页签显隐，避免皮肤高优先级规则同时展开两栏；先于包内最后一份皮肤样式挂载。
- `i18n-additions.json`：补充包中缺少的现有游戏文案，包内同名词条和模板优先。奖杯脚本英文初始化和重建文字节点的来源通过 `sourceZh` 精确补齐，避免中英往返残留英文；不泛化翻译玩家自定义内容。
- `overlay-integration.js`：语言按钮显示目标语种并保持提示为界面当前语种、保留原生轨迹 iframe 名称；避免已完成排序的奖杯列表反复搬动同一批节点；状态小章按当前语言最长文案统一宽度，沿用包内高度、边框与颜色。卡片排列、装饰、尺寸和视觉资源仍由包内完整 CSS 与脚本决定。

以后换包时复核仍需要的增量；不要反向把本目录写进覆盖包或以它修改视觉定稿。

接入 CSS、脚本及其补充字典按覆盖包版本 + 游戏版本独立刷新缓存；包内皮肤、语言与行囊脚本仍使用原包 `VERSION`。

顶栏外壳透传指针事件时，语言按钮单独恢复 `pointer-events: auto`；点按沿用覆盖包原生 handler，桌面点击和手机触屏点按分别验证。

非阻塞加载提示通过独立 CSS 放大现有御剑动画和中英文文案，增加深青柔暗晕；入口、失败状态与皮肤的菜单／剧情显隐保持原样，不改变加载任务或进度。
